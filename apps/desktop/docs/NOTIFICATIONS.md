# Notifications and the system tray

The title bar bell keeps recent task completions, failures and Code approval requests. Select an entry to open its chat, mark all entries read, or clear the list. The list lasts for the app session. The desktop-notification toggle is remembered between launches.

When the app is in the background, supported operating systems also show a quiet native notification. Its text describes the task status without including the prompt or generated content. Selecting it brings Agente forward and opens the chat.

On Windows and Linux, closing a window hides it while the tray icon is available. Running tasks continue. Use the tray menu to show Agente again or choose **Quit** to end the app. If the tray cannot be created, closing keeps the normal window-close behavior. Linux desktops need a system tray host; availability depends on the desktop environment.
