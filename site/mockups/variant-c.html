Index of Capabilities

Built for transparency at every step.

Four core guarantees
FIG. 01

Graded edit matching

Edits match deterministically without guessing; ambiguous hunks refuse cleanly and surface exact candidates.

FIG. 02

Parallel worktree subagents

Read-only tools run in parallel; writing subagents run in isolated git worktrees with independent cost and stop controls.

FIG. 03

Revert & fork history

Rewind file edits back to any sent prompt with redo support, or fork an earlier turn into a fresh session.

FIG. 04

Unified context budget

One arithmetic drives the token meter, compaction trigger, and provider cache reporting across all surfaces.

Local Strata

Cloud APIs or local GGUF.

Connect OpenRouter, DeepSeek, MiniMax, Z.AI, Ollama, LM Studio, or run GGUF models directly with llama.cpp. Everything persists under ~/.agente.
