Architecture

Built for long sessions

01

Model providers

Use OpenRouter, OpenCode Go, DeepSeek, Z.AI (GLM), MiniMax, or any OpenAI-compatible endpoint — or run local GGUF weights via llama.cpp, Ollama, or LM Studio.

02

Parallel worktree subagents

Explore and plan agents run concurrently; writing subagents isolate in separate git worktrees with individual stop controls.

03

Unified context budget

One arithmetic drives token meters, prompt cache telemetry, and automatic compaction at 85% of available room.

04

Local storage

Sessions, attachments, and configuration are stored locally under ~/.agente, or on your own host when running agente serve.

Install

Downloads and packages

Windowsx64 installer · AgenteDesktop-windows-x64.exeDownload LinuxAppImage · x64 portable binaryDownload Debian / Ubuntuamd64 · .deb packageDownload

Verify checksums with AgenteDesktop-SHA256SUMS. On macOS, build from source using the Desktop guide.

mkdir -p ~/.local/bin
curl -fL -o ~/.local/bin/agente \
  https://github.com/fabricio3g/AgenteCode/releases/latest/download/AgenteCode-linux-x64
chmod +x ~/.local/bin/agente
agente

Other builds: Linux arm64 · Windows x64 · Debian amd64 · Debian arm64 · SHA256SUMS.

export AGENTE_TOKEN=$(openssl rand -hex 32)
docker run -d --name agente \
  -p 127.0.0.1:7420:7420 \
  -e AGENTE_TOKEN -e OPENROUTER_API_KEY \
  -v agente-data:/home/agente/.agente \
  -v "$PWD/workspace:/workspace" \
  ghcr.io/fabricio3g/agente-server:latest
