Plate II · Instruments

Desktop, terminal, and server.

One Rust agent loop, one session store, and one approval contract across three calibrated interfaces.

Desktop Workspace

Home for research and DOCX, PPTX, and XLSX artifacts; Code for repository work; Design for visual HTML prototyping.

  • Home, Code, and Design spaces in one shell
  • Preview, edit, and export generated documents
  • Local GGUF inference via llama.cpp (CPU or GPU)
  • Speech-to-text & text-to-speech in seven languages

Terminal UI

Keyboard-first TUI with read-only planning, inline diffs, session tabs, and isolated worktree subagents.

  • Cycle Plan, Build, and Auto modes with Shift+Tab
  • Parallel subagents in isolated git worktrees
  • Revert or fork any conversation from any prompt
  • Agent Client Protocol (ACP) stdio for editors
# keep sessions alive on any host
$ agente serve
$ agente serve --status

# attach from terminal or desktop
$ agente attach

Headless Server

Run the agent runtime as a persistent background daemon with token-authenticated HTTP and WebSocket streams.

  • Persistent background sessions across disconnects
  • Shared tool execution and approval state
  • Prebuilt Docker container image

Plate IV · Strata & Inference

Bring any provider
