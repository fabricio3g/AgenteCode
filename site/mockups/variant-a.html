Desktop, terminal, and server.

Every surface shares the same Rust runtime, session storage, model routing, and tool approval contract.

Desktop Workspace

Home for research and generating DOCX, PPTX, and XLSX documents; Code for repository work; Design for live HTML prototyping.

Design Principles

Built for trust, not spectacle.

An agent should never surprise you. Every file edit, shell command, subagent branch, and token budget is deterministic and inspectable.

01

Explicit edit approvals

File changes and shell commands pause cleanly above the prompt with a full diff. Destructive commands stand out immediately; Enter approves and Esc denies.

02

Parallel worktree subagents

Read-only exploration runs concurrently while writing subagents execute in isolated git worktrees, each with its own live telemetry and independent stop control.

03

Revert & fork any turn

Undo file edits back to any earlier prompt with full redo support, or fork the conversation into a fresh session without losing your place.

04

Cloud APIs or local GGUF

Connect OpenRouter, DeepSeek, MiniMax, Z.AI, Ollama, LM Studio, or run GGUF weights locally via llama.cpp. Everything stays on your disk under ~/.agente.
