Get Agente Code

Rust coding agent and local AI workspace.

Agente Code runs as a desktop application, a terminal UI, and a headless server. Connect cloud or local models, inspect tool calls in real time, and review diffs before changes are written.

Download Desktop Install the CLI
MIT open source Rust core Cloud APIs & local GGUF

Surfaces

Desktop, terminal, and server

All three interfaces use the same Rust agent core, session storage, model settings, and tool execution loop.

Desktop

Use Home for chat, web search, and generating DOCX, PPTX, and XLSX files. Switch to Code for repository work, or Design for visual HTML prototyping.

  • Home, Code, and Design workspaces
  • Preview, edit, and download generated file artifacts
  • Local GGUF inference with llama.cpp (CPU or GPU)
  • Speech-to-text and text-to-speech · seven UI languages

Terminal

Terminal UI for repository tasks with read-only planning, tool confirmation prompts, inline diffs, and multiple session tabs.

  • Cycle Plan, Build, and Auto modes with Shift+Tab
  • Parallel subagents in isolated git worktrees
  • Revert or fork sessions from any user message
  • Agent Client Protocol (ACP) stdio support for editors

Server Preview

Run the agent runtime as a background daemon on a local machine or server, and attach to active sessions from a terminal or Desktop client.

  • Persistent background sessions
  • Shared agent loop and tool execution
  • Token-authenticated HTTP and WebSocket API
  • Prebuilt Docker container image

Tool approvals, diffs, and session controls

Inspect tool execution as it runs, review file modifications before confirming, and manage context usage and session history.

Models and storage

Cloud APIs and local inference

Model providers

Connect cloud providers with your own API keys, or run GGUF models locally via llama.cpp, Ollama, or LM Studio. Reasoning effort levels adapt to each model's capabilities.

Execution modes

Switch between read-only Plan mode, per-action approvals in Build mode, or Auto mode for a turn. Inspect diffs in the transcript and Changes panel.

Local storage

Session transcripts, attachments, and configuration files are stored on disk under ~/.agente, or on your own host when running agente serve.

Install

Downloads and packages

Windowsx64 installer · AgenteDesktop-windows-x64.exeDownload LinuxAppImage · x64 portable binaryDownload Debian / Ubuntuamd64 · .deb packageDownload

Verify checksums with AgenteDesktop-SHA256SUMS. On macOS, build from source using the Desktop guide.

mkdir -p ~/.local/bin
curl -fL -o ~/.local/bin/agente \
  https://github.com/fabricio3g/AgenteCode/releases/latest/download/AgenteCode-linux-x64
chmod +x ~/.local/bin/agente
agente

Other builds: Linux arm64 · Windows x64 · Debian amd64 · Debian arm64 · SHA256SUMS. Configure a provider and model on first launch with /provider and /model.

export AGENTE_TOKEN=$(openssl rand -hex 32)
docker run -d --name agente \
  -p 127.0.0.1:7420:7420 \
  -e AGENTE_TOKEN -e OPENROUTER_API_KEY \
  -v agente-data:/home/agente/.agente \
  -v "$PWD/workspace:/workspace" \
  ghcr.io/fabricio3g/agente-server:latest
